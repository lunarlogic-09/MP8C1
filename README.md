## Deskripsi Program
Program berbasis terminal ini membaca data transaksi penjualan pizza dari file CSV berdelimiter titik koma (`;`), memvalidasi kelayakan data, mengelompokkan tingkat kelengkapan bahan baku (`Sederhana`, `Sedang`, `Lengkap`, `Sangat Lengkap`), menghitung rata-rata harga jual per ukuran (`S`, `M`, `L`) dan kategori bahan, serta menganalisis frekuensi dan prioritas persediaan bahan baku.

## File Utama dalam Repositori
- `mini project tes 2.1.py` — Kode utama program Python.
- `dataset_pizza_35_baris_analisis_bahan_harga.csv` — Dataset transaksi pizza (35 baris, delimiter `;`).
- `README.md` — Dokumentasi panduan penggunaan program.

## Cara Menjalankan Program
1. Pastikan Python 3 terpasang di perangkat.
2. Letakkan file kode program dan file CSV dalam satu folder yang sama.
3. Jalankan program dari terminal di folder proyek:
   ```bash
   python "mini project tes 2.1.py"
